# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository
and choose **Report a vulnerability**. Do not open a public issue for a security problem.

Include the affected contract and function, the steps or a test that reproduces the problem, and its
impact. We will acknowledge the report and keep you informed while it is fixed.

## Scope

The contracts in `src/`. Deployed addresses will be listed in this repository once the contracts are on
mainnet; only those deployments are in scope for production reports.

Known trust assumptions are described in the [trust model](README.md#trust-model) and are not
vulnerabilities by themselves.

## Audit status

The contracts have not been audited.
